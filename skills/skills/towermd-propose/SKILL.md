先读取[共享会话契约](../../references/session-contract.md)。

当前 CLI 尚无公开 propose 命令，后续基线出版入口也未完成。本技能可整理提案材料，不能提交或批准提案；这是整个六技能 M1 验收的已知缺口。

发现慢层或越界需要时，立即停止该部分代码写入。将以下真实材料交给用户：要改变的对象与当前基线、问题和依据、精确差异、受影响模块/任务/接口、至少一个可行备选、建议与验证计划。材料可保存在工作树外的任务记录目录，不能写入 `.towermd/` 或用户慢层目录假装产品提案。

说明“当前版本缺公开提案提交和后续基线出版，需完成产品入口后由人在 App 审阅批准”；保留当前 Run 与相关 Hold/任务 ID。不得使用 baseline submit 冒充后续基线批准，不调用内部 HTTP 或直接改对象，不发明 propose/approve 命令。只有已授权且不依赖这项变更的任务部分可继续；核心任务依赖此变更则停车。
