# 命令行 C0 契约（B 部分）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `towermd` 的每次调用都在 stdout 输出且只输出一个版本化信封 `{v, ok, data, delivered[], next[{cmd,why}], warnings[]}`，并以 0–8 的稳定退出码表达结果。写命令统一用全局 `--request-id`（复用 hub 的 eid 幂等）。输出格式由 `--json`/`--text` 选定，未指定时看 stdout 是否为终端。语言按 `--lang` → `TOWERMD_LANG` → `LC_ALL` → `LANG` → macOS AppleLanguages → en 的顺序决定。开发专属命令收进 `towermd dev`，不保留别名。每个叶子命令都有手写的 JSON Schema，并由测试校验真实输出。

**Architecture:** 新增 `crates/towermd/src/output/`（`code.rs` 错误码与退出码，`envelope.rs` 信封，`lang.rs` 语言，`render.rs` 文本与 JSON 渲染，T9 起加 `schema.rs`，T10 起加 `help.rs`），以及 `src/args.rs`（只放 clap 语法）。`main.rs` 改成“解析 → 取消息 → 执行 → 组信封 → 输出 → stdout 成功后确认送达 → 按错误码退出”。守护进程的客户端函数一律返回 `Result<Value, Failure>`；守护进程的 HTTP 错误体在保留 `error` 键的同时加上 `code`，客户端据此还原错误码。App（src-tauri）改为从信封的 `data` 读守护进程地址。技能与模板最后同步，由一个“文档里的命令都能被 clap 解析”的测试锁住。

**Tech Stack:** Rust stable，edition 2021；clap 4（`mut_subcommand`/`mut_arg`），serde/serde_json，uuid v7，reqwest blocking，axum 0.8；`cargo test`；不新增任何依赖。

## 与设计的偏差

设计文档（`docs/superpowers/specs/2026-10-21-core-devkit-split-and-cli-c0-design.md` 第 3 节）给出了方向，但有些地方与代码的实际情况冲突，或者没有说到。以下是本计划的取舍，执行者不要再改回去：

| 编号 | 偏差 | 理由 |
| --- | --- | --- |
| D1 | 全局 `--json` 只表示输出格式。输入文件一律用位置参数 `<FILE\|->`。`task add --json task.json` 仍能解析，因为它等于“全局 `--json` 加位置参数”。 | 设计中 `--json <文件\|->` 与 `--json` 输出开关同名，clap 中同一个 ID 只能有一种含义。 |
| D2 | 守护进程的错误体是 `{"error": <消息>, "code": <错误码>}`，`hint` 可选。不把 `error` 改名为 `message`。 | App（`src-tauri/src/backend.rs:464`）读的是 `value["error"]`。改名会让 App 与 CLI 同时升级，C0 没有必要承担这个风险。 |
| D3 | 守护进程未单独分类的拒绝按 HTTP 状态映射：`bad()`（400）→ 新增错误码 `rejected`（退出码 6，“被拦下”一类），`denied()` 与其他 409 → `conflict`（4），404 → `not_found`（3），`uncertain` 与其他 500 → `internal`（1）。守护进程已经知道具体原因的地方（租约、纪元、门禁、守卫、未初始化等）在 T4 显式改码。 | 逐个审核约 200 处 `map_err(bad)` 超出 C0。规格的错误码表只是示例，新增 `rejected` 并写进 Schema 与帮助（调用方已决定）。客户端在错误体缺 `code` 时也按同样的 HTTP 状态回退，旧守护进程或漏改的路径不会被误报成 `internal`。 |
| D4 | 新增 `dev draft show <DRAFT_ID>`。`dev scan show` 只接受扫描 ID。 | 设计把 `baseline show` 只映射到 `dev scan show`，但 v0.1.1 的 `baseline show` 同时接受 `d-` 草稿 ID（`daemon.rs:600`），不加这一条就丢功能。 |
| D5 | 专用文本渲染器有三个：`status`、`init`（逐字保留现有中文输出）、`dev trailers`（原样输出 trailer，便于直接写进提交信息）。其余命令用通用的缩进键值渲染。 | 设计只给 `status` 专用渲染器。但 `init` 的文本输出已有测试锁定，`trailers` 的原样输出是技能依赖的行为。 |
| D6 | 实时 `ask` 返回 `pending` 时，信封为 `ok:false`、`code: pending`、退出码 5，`next` 给出 `towermd wait <hold>`。`deferred` 也是退出码 5。`wait` 同理，`answered` 才是成功。`ask --parked` 创建成功即退出码 0。 | 守护进程的 `ask` 立即返回 `pending`（`WaitPlan`）。退出码 5 就是 C0 为“还没有结果，稍后再来”预留的。 |
| D7 | 请求 ID 的覆盖方式：`snapshot` 本身按状态幂等（没有新事件就返回已有提交），只回显请求 ID；扫描任务的 ID 直接用请求 ID（已完成的扫描报告在磁盘上，守护进程重启后同一 ID 仍返回原结果；运行中的扫描只在内存里，被重启打断后同一 ID 会重新开始，见风险 R6）；hub 重建的请求 ID 直接用 `--request-id`，同一个 ID 和同样内容的文件已存在时返回原结果。 | 这三条写路径原来没有请求 ID（见 F2）。这样做改动最小，又能复用 eid 幂等的约定。 |
| D8 | 启用 `help` 子命令。中文的命令说明和参数说明由 `help.rs` 的对照表在运行时覆盖，每个叶子命令都有示例（`after_help`）。clap 自带的标题（`Usage:`、`Commands:`、`Options:`）以及 `-h`/`-V` 的说明保持英文。 | clap 的标题文字是编译期常量，翻译它需要自定义模板，收益太小。 |
| D9 | 全局 `--project <ID>`，以及 `show [PROJECT]` 的位置参数，与当前仓库的项目 ID 不一致时报 `usage`（退出码 2）。 | C0 只支持“当前仓库”，跨项目路由属于后续版本。 |
| D10 | `completion` 推迟到后续版本。 | 它需要 `clap_complete`，属于新增依赖（调用方已决定）。 |
| D11 | 不带参数的 `towermd` 报 `usage`（退出码 2）。 | 规格 FR-198 的“首屏注意力”属于 C1。 |
| D12 | 守护进程的 `api_version` 从 6 升到 7。 | 错误体多了 `code`，扫描和重建的请求体也变了；旧守护进程必须被识别出来。 |
| D13 | `towermd schema dev.draft.submit` 返回 `{command, output, input}`，其中 `input` 就是原来 `baseline schema` 的 S6 Schema。 | 设计没说 `baseline schema` 去哪里。放进统一的 `schema` 命令，就不用再保留一个开发套件专用的子命令。 |
| D14 | CLI 在本地校验 `--request-id` 必须是小写 UUID v7，不符合就报 `usage`。读命令带 `--request-id` 也报 `usage`。 | 守护进程本来就只接受 v7（F1）。在本地挡住，错误码更准，也不会白白启动守护进程。 |
| D15 | 守护进程返回的消息仍是中文，只有 CLI 本地生成的文字随语言切换。 | 守护进程消息的国际化要改约 300 处字符串，留给后续版本。 |
| D16 | `pause <SCOPE>`、`resume <SCOPE>` 用位置参数，C0 只接受一个值 `all`。 | 规格写作 `pause <范围>`，设计写作 `pause all`。位置参数两种写法都能兼容。 |
| D17 | 输出已经成功、但送达确认失败时，只在 stderr 写一条警告，不改变退出码。消息下次还会再送。 | 结果已经交给调用方，再报失败会诱使调用方重试写操作。 |

## 代码事实与设计假设不符之处

- **F1** 守护进程已经要求所有写请求的 `request_id` 是 v7（`task_service.rs:247`，`valid_scan_id`）。设计说的“复用 eid 幂等”早已在服务端成立，CLI 只需要把 ID 暴露成全局参数并回显。
- **F2** 只有三条写路径没有请求 ID：扫描启动（`project_service.rs:509`，处理函数没有请求体）、hub 重建（`business_service.rs:348`，ID 由服务端生成）、快照（`business_service.rs:321`，按状态幂等）。扫描取消天然幂等。草稿提交按内容寻址（`draft_store::submission_id`），本身就是幂等的，不需要请求 ID。
- **F3** 现在的 stdout 是多段 JSON：每条消息一段 `{"message":…}`，然后才是结果。`skills/README.md:21` 明确告诉消费者“不能假设整个 stdout 永远只有一个 JSON 对象”。C0 之后，消息改放在信封的 `delivered[]` 里，这一行必须同步改掉。
- **F4** App 有两处依赖 `daemon ensure`：`src-tauri/src/backend.rs:497` 启动子进程，并把 stdout 直接解析成 `Endpoint`；`crates/towermd/src/app_launch.rs:105` 在进程内调用 `crate::daemon::ensure`，要求返回类型是 `Result<Value, String>`。
- **F5** `ask` 立即返回 `{hold, wait:{status:"pending",…}}`，不会阻塞。原来的 `ask --wait` 与 `wait` 走的是同一个接口。
- **F6** `baseline show` 同时处理扫描 ID 和 `d-` 草稿 ID。
- **F7** G0 校验失败（`task_model::prepare_add`、`check_g0`）都经由 `bad()` 返回 400。如果不显式改码，它们会落进 `rejected`（退出码 6）；T4 把它们改成更准确的 `gate_failed`。
- **F8** 在非 git 目录运行 `init`，现在退出码是 1（`init_cli.rs:136`、`init_cli.rs:363`）；C0 下改为 `not_found`，退出码 3。
- **F9** 提示“需复核”的那行文字现在直接写到 stderr（`daemon.rs:821`），`proposal_cli.rs:77` 断言 stderr 里含“T-removed 需复核”。C0 下它变成信封的 `warnings[]`，并在 stderr 上以 `towermd: 警告：…` 的形式输出，原断言仍然成立。

## 规格与设计的分歧

以下几处，规格（`docs/specs/2026-10-21-spec-towermd-cli.md`、开发套件规格）与设计文档说法不一。本计划一律按设计（以及调用方已做的决定）执行，这里只列出来，留给人来裁决：

1. **`--json`**：规格中 `--json` 既是输出开关，也是 `task add --json <文件|->` 的输入参数；设计沿用了这一写法。本计划按 D1 把输入改成位置参数。
2. **`hub rebuild`**：规格写的是“一步完成并校验”；设计（以及调用方的决定）保持“CLI 发出请求，App 确认”。
3. **`pause` 的参数**：规格是 `pause <范围>`，设计是 `pause all`，见 D16。
4. **`completion`**：规格把它列为 C0；设计和调用方推迟了它，见 D10。
5. **`show`**：规格把它列为 C1；设计放在 C0。本计划按设计在 T6 实现。
6. **守护进程错误体**：设计是 `{code,message,hint}`；本计划为了兼容 App 保留 `error` 键，见 D2。
7. **`help <cmd>` 与示例**：规格要求有；现有代码设置了 `disable_help_subcommand`。本计划在 T10 启用。
8. **FR-198**：规格要求不带参数的 `towermd` 显示注意力摘要（C1）；C0 中它报 `usage`，见 D11。
9. **离线排队**：规格 3.7 的离线排队与 `hub_offline` 在 C0 不实现。错误码已经保留，但没有代码路径会产生它。
10. **`baseline show`**：设计只把它映射到 `dev scan show`，草稿还需要 `dev draft show`，见 D4。
11. **专用文本渲染器**：设计只给 `status`；本计划还给了 `init` 和 `dev trailers`，见 D5。
12. **开发套件规格里的命令名**：`docs/specs/2026-10-21-spec-towermd-development-kit.md` 仍写 `towermd baseline submit`、`towermd check`、`towermd finish`、`towermd trailers`（第 381、395、447、455、542–547、553 行等）。设计把它们收进了 `towermd dev`。规格属于人定内容，本计划不修改，见 Q7。
13. **错误码集合**：设计第 4 节只列了具体的错误映射，没说未分类的拒绝算什么。调用方决定按 HTTP 状态映射，并新增规格中没有的 `rejected`（退出码 6），见 D3。规格的错误码表需要补上这一项。
14. **`schema dev.draft.submit`**：设计的 `schema <命令>` 只描述输出；草稿提交还需要输入 Schema，见 D13。

```rust
    Internal,

impl ErrorCode {
    pub const ALL: [ErrorCode; 17] = [
        ErrorCode::Usage,
        ErrorCode::TooLong,
        ErrorCode::NotFound,
        ErrorCode::NotInitialized,
        ErrorCode::LeaseBusy,
        ErrorCode::StaleEpoch,
        ErrorCode::Conflict,
        ErrorCode::Pending,

        ErrorCode::GateFailed,
        ErrorCode::NeedsProposal,
        ErrorCode::Rejected,
        ErrorCode::NeedsHuman,
        ErrorCode::DaemonUnavailable,
        ErrorCode::HubOffline,
        ErrorCode::Internal,
    ];

    pub fn as_str(self) -> &'static str {
        match self {
            ErrorCode::Usage => "usage",
            ErrorCode::TooLong => "too_long",
            ErrorCode::NotFound => "not_found",
            ErrorCode::NotInitialized => "not_initialized",
            ErrorCode::LeaseBusy => "lease_busy",
            ErrorCode::StaleEpoch => "stale_epoch",
            ErrorCode::Conflict => "conflict",
            ErrorCode::Pending => "pending",
            ErrorCode::Deferred => "deferred",
            ErrorCode::GuardBlocked => "guard_blocked",
            ErrorCode::GateFailed => "gate_failed",
            ErrorCode::NeedsProposal => "needs_proposal",
            ErrorCode::Rejected => "rejected",
            ErrorCode::NeedsHuman => "needs_human",
            ErrorCode::DaemonUnavailable => "daemon_unavailable",
            ErrorCode::HubOffline => "hub_offline",
            ErrorCode::Internal => "internal",
        }
    }

    pub fn parse(text: &str) -> Option<Self> {
        Self::ALL.into_iter().find(|code| code.as_str() == text)
    }

    /// Exit status: 0 ok, 1 internal, 2 usage, 3 missing, 4 state conflict,
    /// 5 not yet, 6 stopped by a guard, gate or rule, 7 needs a person,
    /// 8 unreachable.
    pub fn exit(self) -> u8 {
        match self {
            ErrorCode::Internal => 1,
            ErrorCode::Usage | ErrorCode::TooLong => 2,
            ErrorCode::NotFound | ErrorCode::NotInitialized => 3,
            ErrorCode::LeaseBusy | ErrorCode::StaleEpoch | ErrorCode::Conflict => 4,
            ErrorCode::Pending | ErrorCode::Deferred => 5,
            ErrorCode::GuardBlocked | ErrorCode::GateFailed | ErrorCode::NeedsProposal | ErrorCode::Rejected => 6,
            ErrorCode::NeedsHuman => 7,
            ErrorCode::DaemonUnavailable | ErrorCode::HubOffline => 8,
        }
    }

    /// Codes for which repeating the same call later can succeed unchanged.
    pub fn transient(self) -> bool {
        matches!(
            self,
            ErrorCode::Pending
                | ErrorCode::Deferred
                | ErrorCode::DaemonUnavailable
                | ErrorCode::HubOffline
                | ErrorCode::LeaseBusy
        )
    }
}
```

```rust
    pub message: String,

        self
    }

pub struct Retry {
    pub safe: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub request_id: Option<String>,
}

#[derive(Debug, Serialize)]
pub struct ErrorBody {
    pub code: ErrorCode,
    pub message: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub hint: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub retry: Option<Retry>,
}

#[derive(Debug, Serialize)]
pub struct Envelope {
    pub v: u8,
    pub ok: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub data: Option<Value>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub error: Option<ErrorBody>,
    pub delivered: Vec<Value>,
    pub next: Vec<Next>,
    pub warnings: Vec<String>,
}

impl Envelope {
    pub fn success(done: Done, request_id: Option<&str>) -> Self {
        let mut data = done.data;
        if let (Some(id), Value::Object(map)) = (request_id, &mut data) {
            map.entry("request_id").or_insert_with(|| Value::String(id.to_owned()));
        }
        Self {
            v: VERSION,
            ok: true,
            data: Some(data),
            error: None,
            delivered: Vec::new(),
            next: done.next,
            warnings: done.warnings,
        }
    }

    pub fn failure(failure: Failure, request_id: Option<&str>) -> Self {
        // A write that carried a request ID is always safe to repeat with
        // the same ID: the hub deduplicates by eid. Without an ID only
        // transient conditions are worth retrying unchanged.
        let retry = match failure.code {
            ErrorCode::Usage | ErrorCode::TooLong => None,
            _ if request_id.is_some() => Some(Retry { safe: true, request_id: request_id.map(str::to_owned) }),
            code if code.transient() => Some(Retry { safe: true, request_id: None }),
            _ => None,
        };
        Self {
            v: VERSION,
            ok: false,
            data: failure.data,
            error: Some(ErrorBody { code: failure.code, message: failure.message, hint: failure.hint, retry }),
            delivered: Vec::new(),
            next: failure.next,
            warnings: Vec::new(),
        }
    }

    pub fn exit(&self) -> u8 {
        self.error.as_ref().map_or(0, |error| error.code.exit())
    }
}
```

```rust
pub fn current() -> Lang {

/// `zh_CN.UTF-8`, `zh-Hans-CN`, `zh` → Chinese; any other real tag → English.
/// Empty values and the POSIX defaults `C`/`POSIX` decide nothing.
pub fn from_tag(tag: &str) -> Option<Lang> {
    let base = tag.split(['.', '@']).next().unwrap_or("").trim().replace('_', "-").to_ascii_lowercase();
    if base.is_empty() || base == "c" || base == "posix" {
        return None;
    }
    let chinese = base == "zh" || ["zh-cn", "zh-sg", "zh-hans"].iter().any(|prefix| base.starts_with(prefix));
    Some(if chinese { Lang::ZhCn } else { Lang::En })
}

        .or_else(|| apple().as_deref().and_then(from_tag))
        .unwrap_or(Lang::En)
}

/// `--lang` must be honoured even when clap rejects the rest of the line.
pub fn flag_from_args(args: &[OsString]) -> Option<String> {
    let mut iter = args.iter().skip(1).map(|arg| arg.to_string_lossy());
    while let Some(arg) = iter.next() {
        if arg == "--" {
            break;
        }
        if arg == "--lang" {
            return iter.next().map(|value| value.into_owned());
        }
        if let Some(value) = arg.strip_prefix("--lang=") {
            return Some(value.to_owned());
        }
    }
    None
}

    lang
}
```

```rust
//! Shared checks for the C0 stdout envelope; included with #[path].
#![allow(dead_code)]
use serde_json::Value;
use std::process::Output;

pub fn exit_for(code: &str) -> i32 {
    match code {
        "internal" => 1,
        "usage" | "too_long" => 2,
        "not_found" | "not_initialized" => 3,
        "lease_busy" | "stale_epoch" | "conflict" => 4,
        "pending" | "deferred" => 5,
        "guard_blocked" | "gate_failed" | "needs_proposal" | "rejected" => 6,
        "needs_human" => 7,
        "daemon_unavailable" | "hub_offline" => 8,
        other => panic!("unknown error code {other}"),
    }
}

/// stdout must hold exactly one envelope whose code matches the exit status.
pub fn parse(output: &Output) -> Value {
    let envelope: Value = serde_json::from_slice(&output.stdout).unwrap_or_else(|error| {
        panic!(
            "stdout is not one JSON envelope ({error}): {}\nstderr: {}",
            String::from_utf8_lossy(&output.stdout),
            String::from_utf8_lossy(&output.stderr)
        )
    });
    assert_eq!(envelope["v"], 1, "{envelope}");
    for key in ["delivered", "next", "warnings"] {
        assert!(envelope[key].is_array(), "{key}: {envelope}");
    }
    let ok = envelope["ok"].as_bool().expect("ok is a boolean");
    let exit = if ok { 0 } else { exit_for(envelope["error"]["code"].as_str().expect("error.code")) };
    assert_eq!(output.status.code(), Some(exit), "{envelope}\nstderr: {}", String::from_utf8_lossy(&output.stderr));
    envelope
}

pub fn data(output: &Output) -> Value {
    let envelope = parse(output);
    assert_eq!(envelope["ok"], true, "{envelope}\nstderr: {}", String::from_utf8_lossy(&output.stderr));
    envelope["data"].clone()
}

pub fn code(output: &Output) -> String {
    let envelope = parse(output);
    assert_eq!(envelope["ok"], false, "{envelope}");
    envelope["error"]["code"].as_str().unwrap().to_owned()
}
```

```rust
//! Text and JSON rendering of one envelope. stdout gets the envelope (JSON)
//! or the result and delivered messages (text); stderr gets diagnostics.
use std::ffi::OsString;
use std::io::{self, Write};

use serde_json::Value;

use super::lang::{self, Lang};
use super::Envelope;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Format {
    Json,
    Text,
}

pub fn format(json: bool, text: bool, tty: bool) -> Format {
    match (json, text) {
        (true, _) => Format::Json,
        (false, true) => Format::Text,
        _ if tty => Format::Text,
        _ => Format::Json,
    }
}

/// Used when clap rejected the line, so the parsed flags are unavailable.
pub fn format_from_args(args: &[OsString], tty: bool) -> Format {
    let flags: Vec<_> = args.iter().skip(1).map(|arg| arg.to_string_lossy()).take_while(|arg| arg != "--").collect();
    format(flags.iter().any(|arg| arg == "--json"), flags.iter().any(|arg| arg == "--text"), tty)
}

/// Writes stdout first. Only a stdout failure is an error: the caller then
/// must not acknowledge delivered messages.
pub fn emit(envelope: &Envelope, format: Format, quiet: bool, command: &str, out: &mut dyn Write, err: &mut dyn Write) -> io::Result<()> {
    let body = match format {
        Format::Json => {
            let mut bytes = serde_json::to_vec_pretty(envelope)?;
            bytes.push(b'\n');
            bytes
        }
        Format::Text => text_stdout(envelope, quiet, command).into_bytes(),
    };
    out.write_all(&body)?;
    out.flush()?;
    for line in stderr_lines(envelope, format) {
        let _ = writeln!(err, "{line}");
    }
    Ok(())
}

fn text_stdout(envelope: &Envelope, quiet: bool, command: &str) -> String {
    let mut text = String::new();
    for message in &envelope.delivered {
        let actor = message["actor"].as_str().unwrap_or("?");
        let body = message["text"].as_str().unwrap_or("");
        text.push_str(&format!("{} {actor}: {body}\n", lang::pick("[message]", "[消息]")));
    }
    if envelope.ok && !quiet {
        if let Some(data) = &envelope.data {
            text.push_str(&data_text(command, data));
        }
        for next in &envelope.next {
            text.push_str(&format!("{} {}  # {}\n", lang::pick("next:", "下一步："), next.cmd, next.why));
        }
    }
    text
}

fn stderr_lines(envelope: &Envelope, format: Format) -> Vec<String> {
    let mut lines: Vec<String> =
        envelope.warnings.iter().map(|warning| format!("towermd: {}{warning}", lang::pick("warning: ", "警告："))).collect();
    let Some(error) = &envelope.error else { return lines };
    match format {
        Format::Json => lines.push(format!("towermd: {}: {}", error.code.as_str(), error.message)),
        Format::Text => {
            lines.push(format!("towermd: {}", error.message));
            if let Some(hint) = &error.hint {
                lines.push(format!("towermd: {}{hint}", lang::pick("hint: ", "提示：")));
            }
            if let Some(id) = error.retry.as_ref().and_then(|retry| retry.request_id.as_deref()) {
                lines.push(format!(
                    "towermd: {}",
                    lang::pick(format!("safe to retry with --request-id {id}"), format!("可沿用 --request-id {id} 安全重试"))
                ));
            }
            for next in &envelope.next {
                lines.push(format!("towermd: {} {}  # {}", lang::pick("next:", "下一步："), next.cmd, next.why));
            }
        }
    }
    lines
}

fn data_text(command: &str, data: &Value) -> String {
    match command {
        "status" => status_text(lang::current(), data),
        "init" => init_text(lang::current(), data),
        // Raw trailers so `git commit -m "$(towermd --text dev trailers T-1)"` works.
        "trailers" | "dev.trailers" => data["trailers"].as_str().unwrap_or_default().to_owned(),
        _ => value_text(data, 0),
    }
}

fn status_text(lang: Lang, data: &Value) -> String {
    let field = |key: &str| data[key].as_str().unwrap_or("-").to_owned();
    let run = &data["current_run"];
    let current = if run.is_null() {
        lang::pick_in(lang, "none", "无").to_owned()
    } else {
        format!("{} ({})", run["binding"]["id"].as_str().unwrap_or("?"), run["task"].as_str().unwrap_or("?"))
    };
    let labels = lang::pick_in(lang, ["project", "branch", "revision", "state", "current run"], ["项目", "分支", "版本", "状态", "当前运行"]);
    let colon = lang::pick_in(lang, ": ", "：");
    let values = [field("project_id"), field("branch"), field("revision"), field("runtime_status"), current];
    labels.iter().zip(values).map(|(label, value)| format!("{label}{colon}{value}\n")).collect()
}

fn init_text(lang: Lang, data: &Value) -> String {
    let strings = |key: &str| data[key].as_array().into_iter().flatten().filter_map(Value::as_str).map(str::to_owned).collect::<Vec<_>>();
    let reused = data["reused_config"].as_bool().unwrap_or(false);
    let (id, docs, created, warning, hint, closing) = lang::pick_in(
        lang,
        ("Project ID", "User docs directory", "Created:", "Warning: ", "Hint: ", "These files are not committed; review and commit them yourself.\n"),
        ("项目 ID", "用户文档目录", "新建：", "警告：", "提示：", "以上文件未提交，请检查后自行提交。\n"),
    );
    let origin = match (lang, reused) {
        (Lang::En, true) => " (reused)",
        (Lang::En, false) => " (new)",
        (Lang::ZhCn, true) => "（沿用已有）",
        (Lang::ZhCn, false) => "（新生成）",
    };
    let colon = lang::pick_in(lang, ": ", "：");
    let mut text = format!(
        "{id}{colon}{}{origin}\n{docs}{colon}{}\n",
        data["project_id"].as_str().unwrap_or(""),
        data["docs_dir"].as_str().unwrap_or("")
    );
    let files = strings("created");
    if !files.is_empty() {
        text.push_str(&format!("{created}\n"));
        files.iter().for_each(|file| text.push_str(&format!("  {file}\n")));
    }
    strings("warnings").iter().for_each(|item| text.push_str(&format!("{warning}{item}\n")));
    strings("hints").iter().for_each(|item| text.push_str(&format!("{hint}{item}\n")));
    text.push_str(closing);
    text
}

/// Indented key/value text for every result without a dedicated renderer.
fn value_text(value: &Value, indent: usize) -> String {
    let pad = "  ".repeat(indent);
    let nested = |value: &Value| matches!(value, Value::Object(map) if !map.is_empty()) || matches!(value, Value::Array(items) if !items.is_empty());
    match value {
        Value::Object(map) => map
            .iter()
            .map(|(key, item)| if nested(item) { format!("{pad}{key}:\n{}", value_text(item, indent + 1)) } else { format!("{pad}{key}: {}\n", scalar(item)) })
            .collect(),
        Value::Array(items) => items
            .iter()
            .map(|item| if nested(item) { format!("{pad}-\n{}", value_text(item, indent + 1)) } else { format!("{pad}- {}\n", scalar(item)) })
            .collect(),
        other => format!("{pad}{}\n", scalar(other)),
    }
}

fn scalar(value: &Value) -> String {
    match value {
        Value::String(text) => text.clone(),
        Value::Null => "-".into(),
        Value::Array(_) => "[]".into(),
        Value::Object(_) => "{}".into(),
        other => other.to_string(),
    }
}
```

```rust
fn clap_exit(error: clap::Error, format: Format) -> ExitCode {
    if !error.use_stderr() {
        // --help and --version are plain text by design.
        return match error.print() {
            Ok(()) => ExitCode::SUCCESS,
            Err(error) => {
                let _ = writeln!(io::stderr().lock(), "towermd: {error}");
                ExitCode::FAILURE
            }
        };
    }
    let message = if error.kind() == clap::error::ErrorKind::DisplayHelpOnMissingArgumentOrSubcommand {
        lang::pick("missing command", "缺少命令").to_owned()
    } else {
        let rendered = error.render().to_string();
        rendered.lines().next().unwrap_or_default().trim_start_matches("error: ").to_owned()
    };
    let failure = Failure::new(ErrorCode::Usage, message).hint(lang::pick("run `towermd --help` for usage", "运行 `towermd --help` 查看用法"));
    finish(Err(failure), Delivery::default(), None, format, false, "")

fn request_id(given: Option<String>, write: bool) -> Result<Option<String>, Failure> {

/// Answers and interjections read for this call. They are acknowledged only
/// after the envelope carrying them reached stdout.
#[derive(Default)]
struct Delivery {
    messages: Vec<Value>,
    warnings: Vec<String>,
}

impl Delivery {
    fn fetch(&mut self, run: Option<&str>) -> Result<(), Failure> {
        let value = daemon::fetch_messages(run)?;
        if let Some(review) = value.get("needs_review").filter(|review| !review.is_null()) {
            let task = review["task"].as_str().unwrap_or("?");
            let baseline = review["baseline"].as_str().unwrap_or("?");
            let warning = lang::pick(
                format!("task {task} needs review: the new baseline affects its grant {baseline}; review the task before continuing."),
                format!("任务 {task} 需复核：新基线影响了原授权 {baseline}，请先审阅任务再继续执行。"),
            );
            if !self.warnings.contains(&warning) {
                self.warnings.push(warning);
            }
        }
        for message in value["messages"].as_array().ok_or("消息响应格式无效")? {
            let seen = self.messages.iter().any(|known| known["message"] == message["message"] && known["run"] == message["run"]);
            if !seen {
                self.messages.push(message.clone());
            }
        }
        Ok(())
    }

    /// After ask/wait/answer the result itself may have produced messages.
    fn refresh(&mut self, run: Option<&str>) {
        if let Err(failure) = self.fetch(run) {
            self.warnings.push(failure.message);
        }
    }

    fn acknowledge(&self) -> Vec<String> {
        self.messages
            .iter()
            .filter_map(|message| daemon::ack_message(message).err().map(|failure| (message, failure)))
            .map(|(message, failure)| {
                let id = message["message"].as_str().unwrap_or("?");
                lang::pick(
                    format!("message {id} was not acknowledged ({}); it will be delivered again", failure.message),
                    format!("消息 {id} 未确认送达（{}），下次会再次送出", failure.message),
                )
            })
            .collect()
    }
}

fn finish(result: Result<Done, Failure>, delivery: Delivery, request_id: Option<&str>, format: Format, quiet: bool, command: &str) -> ExitCode {
    let mut envelope = match result {
        Ok(done) => Envelope::success(done, request_id),
        Err(failure) => Envelope::failure(failure, request_id),
    };
    envelope.delivered = delivery.messages.clone();
    for warning in &delivery.warnings {
        if !envelope.warnings.contains(warning) {
            envelope.warnings.push(warning.clone());
        }
    }
    let written = render::emit(&envelope, format, quiet, command, &mut io::stdout().lock(), &mut io::stderr().lock());
    if let Err(error) = written {
        // Nothing reached the caller, so nothing is acknowledged.
        let _ = writeln!(io::stderr().lock(), "towermd: {}{error}", lang::pick("could not write the result: ", "无法写出结果："));
        return ExitCode::FAILURE;
    }
    for warning in delivery.acknowledge() {
        let _ = writeln!(io::stderr().lock(), "towermd: {}{warning}", lang::pick("warning: ", "警告："));
    }
    ExitCode::from(envelope.exit())
}

fn in_project(run: Option<&str>) -> Result<bool, Failure> {

fn read_json_input(path: &Path) -> Result<Value, Failure> {
    let file = std::fs::File::open(path).map_err(|error| {
        let code = if error.kind() == io::ErrorKind::NotFound { ErrorCode::NotFound } else { ErrorCode::Usage };
        Failure::new(code, format!("{}: {error}", path.display()))
    })?;

}

fn read_json_from(reader: &mut impl Read, name: &str) -> Result<Value, Failure> {
    let mut bytes = Vec::new();
    reader.take(MAX_INPUT + 1).read_to_end(&mut bytes).map_err(|error| format!("{name}: {error}"))?;
    if bytes.len() as u64 > MAX_INPUT {
        return Err(Failure::new(ErrorCode::TooLong, lang::pick(format!("{name}: input exceeds 2 MiB"), format!("{name}：输入超过 2 MiB"))));
    }
    serde_json::from_slice(&bytes).map_err(|error| {
        Failure::new(ErrorCode::Usage, lang::pick(format!("{name}: invalid JSON: {error}"), format!("{name}：JSON 无效：{error}")))
    })
}

fn run_init(path: Option<PathBuf>, docs_dir: Option<String>) -> Result<Value, Failure> {
```

```rust
/// Error body `{"error", "code"?, "hint"?}`. Without a known code the HTTP
/// status decides (D3), so an old or unconverted path is never `internal` by accident.
fn daemon_failure(status: reqwest::StatusCode, value: &Value) -> Failure {
    let message = value.get("error").and_then(Value::as_str).unwrap_or("守护进程请求失败");
    let code = value.get("code").and_then(Value::as_str).and_then(ErrorCode::parse).unwrap_or(match status.as_u16() {
        400 => ErrorCode::Rejected,
        404 => ErrorCode::NotFound,
        409 => ErrorCode::Conflict,
        _ => ErrorCode::Internal,
    });
    let failure = Failure::new(code, message);
    match value.get("hint").and_then(Value::as_str) {
        Some(hint) => failure.hint(hint),
        None => failure,
    }
}
```

```rust
/// `ask` returns `{hold, wait:{status}}`; `wait` returns the status directly.
/// Waiting is exit 5 so a script can tell "not yet" from failure (D6).
fn classify_wait(value: Value, hold: Option<&str>, parked: bool) -> Result<Value, Failure> {
    let status = value.get("wait").unwrap_or(&value)["status"].as_str().unwrap_or_default().to_owned();
    let code = match status.as_str() {
        "pending" => ErrorCode::Pending,
        "deferred" => ErrorCode::Deferred,
        _ => return Ok(value),
    };
    if parked {
        return Ok(value);
    }
    let hold = hold.or(value["hold"].as_str()).unwrap_or("<hold>").to_owned();
    Err(Failure::new(code, lang::pick(format!("question {hold} is {status}"), format!("问题 {hold} 仍在等待（{status}）")))
        .next(Next::new(format!("towermd wait {hold}"), lang::pick("wait for the answer again", "继续等待回答")))
        .data(value))
}

    Failure::new(

        ),
    )
    .next(Next::new("towermd up", lang::pick("let the person answer in the App", "请人在 App 中回答")))
}
```

```rust
/// A wait that ends while work is still running is exit 5 (D6).
fn classify_progress(value: Value, again: String) -> Result<Value, Failure> {
    if !matches!(value["status"].as_str(), Some("queued" | "running")) {
        return Ok(value);
    }
    Err(Failure::new(ErrorCode::Pending, lang::pick("still running", "仍在运行"))
        .next(Next::new(again, lang::pick("wait again (at most 90 s per call)", "再次等待（每次最多 90 秒）")))
        .data(value))
}

/// A finished verification that did not pass is a failed gate, not a report.
fn classify_finish(value: Value, again: String) -> Result<Value, Failure> {
    let value = classify_progress(value, again)?;
    if !matches!(value["status"].as_str(), Some("failed" | "interrupted")) {
        return Ok(value);
    }
    let message = value["error"].as_str().map(str::to_owned)
        .unwrap_or_else(|| lang::pick("verification did not pass", "验证未通过").to_owned());
    Err(Failure::new(ErrorCode::GateFailed, message).data(value))
}

/// Until T9 only the S6 submission input has a schema.
fn schema(name: Option<&str>) -> Result<Value, Failure> {
    match name {
        Some("dev.draft.submit") => Ok(json!({"command": "dev.draft.submit", "input": towermd_devkit::baseline::schema()})),
        Some(other) => Err(Failure::new(ErrorCode::NotFound, format!("{other}: no schema"))),
        None => Err(Failure::new(ErrorCode::Usage, "schema needs a command name")),
    }
```

```rust
fn load(name: &str) -> Value {

/// Checks the subset of JSON Schema used by crates/towermd/schema.
pub fn validate(schema: &Value, value: &Value, at: &str) {
    if let Some(kind) = schema["type"].as_str() {
        let ok = match kind {
            "object" => value.is_object(),
            "array" => value.is_array(),
            "string" => value.is_string(),
            "boolean" => value.is_boolean(),
            "integer" => value.is_i64() || value.is_u64(),
            "number" => value.is_number(),
            "null" => value.is_null(),
            other => panic!("{at}: unsupported type {other}"),
        };
        assert!(ok, "{at}: expected {kind}, got {value}");
    }
    if let Some(allowed) = schema["enum"].as_array() {
        assert!(allowed.contains(value), "{at}: {value} not in {allowed:?}");
    }
    for key in schema["required"].as_array().into_iter().flatten() {
        let key = key.as_str().unwrap();
        assert!(value.get(key).is_some(), "{at}: missing {key} in {value}");
    }
    if let Some(properties) = schema["properties"].as_object() {
        for (key, sub) in properties {
            if let Some(child) = value.get(key) {
                validate(sub, child, &format!("{at}.{key}"));
            }
        }
    }
    if let (Some(items), Some(array)) = (schema.get("items"), value.as_array()) {
        for (index, child) in array.iter().enumerate() {
            validate(items, child, &format!("{at}[{index}]"));
        }
    }
}

/// Dotted leaf name of a towermd argv, skipping global options.
pub fn command_name(args: &[&str]) -> String {
    let mut words = Vec::new();
    let mut iter = args.iter();
    while let Some(arg) = iter.next() {
        match *arg {
            "--run" | "--lang" | "--request-id" | "--project" => { iter.next(); }
            "--json" | "--text" | "-q" | "--quiet" => {}
            word if word.starts_with('-') => {}
            word => words.push(word),
        }
    }
    let depth = match words.first().copied() {
        Some("task" | "hub" | "daemon") => 2,
        Some("dev") if matches!(words.get(1).copied(), Some("scan" | "draft")) => 3,
        Some("dev") => 2,
        _ => 1,
    };
    words.into_iter().take(depth).collect::<Vec<_>>().join(".")
}

/// Envelope plus per-command data check; returns `data`.
pub fn data_checked(args: &[&str], output: &Output) -> Value {
    let data = data(output);
    let name = command_name(args);
    validate(&load(&name), &data, &name);
    let read = args.contains(&"--wait") || matches!(name.as_str(), "show" | "task.show" | "status" | "wait" | "schema" | "dev.check" | "dev.scan.wait" | "dev.scan.show" | "dev.draft.template" | "dev.draft.show" | "dev.draft.ls" | "daemon.ensure" | "daemon.status" | "daemon.stop" | "init" | "up" | "dev.scan.cancel" | "dev.draft.submit");
    if !read {
        assert!(data["request_id"].is_string(), "{name}: write without request_id: {data}");
    }
    data
}
```

（`dev.scan.cancel`、`dev.draft.submit` 不带请求 ID（T8），所以也列在 `read` 里；`dev finish --wait` 靠 `--wait` 排除；`ask --parked` 是写命令，保持检查。）

并在 `parse` 的末尾、`envelope` 返回之前加一行：`validate(&load("envelope"), &envelope, "envelope");`。这样所有走 `parse` 的调用（`data`、`code`）都校验信封本身。

注意 `command_name` 只看位置词：带值的选项必须在上面的列表里，否则它的值会被当成命令词。调用里出现 `--option`、`--producer` 之类的子命令选项时，它们的值位于命令词之后，`take(depth)` 已经截掉，不受影响；`--run` 等全局选项都在列表里。

```rust
pub fn shell_words(line: &str) -> Vec<String> {
    let mut words = Vec::new();
    let mut word = String::new();
    let mut quoted = false;
    let mut started = false;
    for ch in line.chars() {

            ch => { word.push(ch); started = true; }
        }
    }
```

```rust
fn apply(mut command: Command, path: &str, lang: Lang) -> Command {

        command = command.about(pick_in(lang, *en, *zh));

    for (_, id, en, zh) in ARGS.iter().filter(|(p, _, _, _)| *p == path) {

        command = command.mut_subcommand(name, |sub| apply(sub, &child, lang));
    }
    command
```

```rust
fn parse_ensure_output(stdout: &[u8]) -> Result<Endpoint, String> {
```
